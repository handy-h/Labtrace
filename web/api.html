LabTrace API 参考

所有接口路径前缀为 /api/v1

系统

方法路径说明
GET/ping健康检查 / 版本信息
GET/ocr/quota查询 OCR 月度额度
PUT/ocr/quota手动调整 OCR 额度

受检者

方法路径说明
GET/subjects列表 (?search=关键词)
POST/subjects创建
GET/subjects/:id详情
PUT/subjects/:id更新
DELETE/subjects/:id删除

医院

方法路径说明
GET/hospitals列表
POST/hospitals创建
PUT/hospitals/:id更新
DELETE/hospitals/:id删除

检验项目

方法路径说明
GET/test-items列表 (?category=分类)
POST/test-items创建
PUT/test-items/:id更新
DELETE/test-items/:id删除

检验报告

方法路径说明
POST/ocr/upload上传并 OCR 识别
GET/reports报告列表 (带筛选)
GET/reports/:id报告详情 (含项目)
PUT/reports/:id更新报告字段
PUT/reports/:id/items/:itemId更新单个项目
DELETE/reports/:id/items/:itemId删除单个项目
POST/reports/:id/confirm确认报告
POST/reports/:id/import导入报告
POST/reports/:id/re-ocr重新 OCR
GET/reports/:id/image查看原始图片/PDF
GET/reports/:id/ocr-blocksOCR 识别块
POST/reports/:id/apply-mapping应用列映射

影像报告

方法路径说明
GET/imaging-report-types报告类型列表
GET/imaging-exam-items检查项目列表
POST/imaging/upload上传影像报告
GET/imaging-reports影像报告列表
GET/imaging-reports/:id影像报告详情

仪表盘 & 趋势

方法路径说明
GET/dashboard/summary概览统计
GET/dashboard/anomalies异常项目列表 (带筛选分页)
GET/trend/data趋势数据 (?subject_id=)

备份 & 审计

方法路径说明
POST/backups/export导出加密备份
POST/backups/import导入恢复备份
GET/backups备份历史
GET/audit-logs审计日志 (带筛选)
POST/audit-logs/verify验证审计日志完整性

批量导入

方法路径说明
POST/batch/upload批量上传检验报告
POST/batch/confirm确认批量导入
POST/batch/imaging/upload批量上传影像报告
POST/batch/imaging/confirm确认批量导入影像
